# lizard wizard os
An OS written in rust using some tutorials. The goal is to entertain myself with the development of an Operating System, and most importantly; learn more about how they work!
I've always been interested in low-level systems like this, figuring out how they work. Developing while learning is great and it'll teach you everything about OS's and it'll even help you learn rust, so for anyone coming here to learn as well: i strongly recommend following the tutorials i've been using!

## why lizard wizard os
I've given this name to the OS because it sounds fun. thats realy the only reason.

## what are my goals
1. make a working kernel [50%-ish finished]
2. add drivers for keyboard, so we can interact with lizwiz
3. make it do more than printing hello
4. add more drivers to make the os a decent functioning command line OS
5. someday, add a desktop environment

Will these points actually get completed? no, probably not. But i certainly will try to continue the development of lizwiz (hey look, a new nickname already!)
